# v1.0.0 checklist

What had to be true before `v1.0.0` was tagged. Each item is derived from something this repository
already promises (AGENT.md, API.md, SECURITY.md, the decisions) and says how it is verified. The
state column is what was observed on 2026-11-23 at the release candidate, `56e4356`: the last commit that
changes Go code before the release. ✅ = holds, with the evidence.

After 1.0, Go's module rules make every exported name of `github.com/univeros/polaris.go` part of
the v1 compatibility promise in the eyes of its users and their tools: a break needs `/v2`. That is
why the API items come first.

## Decided for 1.0

- The Go versions supported, and the dependencies before their own 1.0 (`crewjam/saml`, `otelhttp`,
  `skip2/go-qrcode`): decision 82.
- The default JWT `kid` is the RFC 7638 thumbprint; the old value stays accepted and published as an alias
  of each key, so no deployment needs a rollover (decision 73).
- `APP_KEY` is fixed for the life of a deployment in 1.x, written down in `config.Secrets`, SECURITY.md and
  docs/stored-formats.md; a key ring can be added later without a format change (decision 73).
