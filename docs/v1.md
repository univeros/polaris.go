# v1.0.0 checklist

What must be true before `v1.0.0` is tagged. Each item is derived from something this repository
already promises (AGENT.md, API.md, SECURITY.md, the decisions) and says how it is verified. The
state column is what was observed on 2026-11-22 at `v0.3.1` (`d316d38`); update it as items close.
✅ = holds today, with the evidence; **open** = work or a decision is left.

After 1.0, Go's module rules make every exported name of `github.com/univeros/polaris.go` part of
the v1 compatibility promise in the eyes of its users and their tools: a break needs `/v2`. That is
why the API items come first.
