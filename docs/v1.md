# v1.0.0 checklist

What must be true before `v1.0.0` is tagged. Each item is derived from something this repository
already promises (AGENT.md, API.md, SECURITY.md, the decisions) and says how it is verified. The
state column is what was observed on 2026-11-22 at `v0.3.1` (`d316d38`); update it as items close.
✅ = holds today, with the evidence; **open** = work or a decision is left.

After 1.0, Go's module rules make every exported name of `github.com/univeros/polaris.go` part of
the v1 compatibility promise in the eyes of its users and their tools: a break needs `/v2`. That is
why the API items come first.

## Decisions to make before 1.0

These are not promised anywhere yet; 1.0 is the moment to decide them.

- The Go versions supported (today `go 1.26.0`, toolchain `go1.26.11`).
- Pre-1.0 dependencies on the stable path: `crewjam/saml` v0.6 (with a reviewed govulncheck ignore),
  `otelhttp` v0.72, `skip2/go-qrcode` (a 2020 pseudo-version). Keep, vendor the needed part, or
  replace.
- The default JWT `kid` (decision 71): SHA-256 of the PEM text, so re-encoding the same key changes
  it. Keep it and recommend `AUTH_JWT_KID`, or move to the RFC 7638 thumbprint with one rollover.
- `APP_KEY` rotation (decision 71): none today, so the 1.x promise says `APP_KEY` is fixed for the
  life of a deployment, or a key-id byte and a keyring come first (additive).
