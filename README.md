# Polaris for Go

The Go port of Polaris (`univeros/polaris-core`): self-hosted authentication, MFA,
organizations and RBAC, and agent sign-in (API keys, OAuth 2.1 / OIDC provider, agents with grants,
approvals and receipts, MCP), wire-, database- and token-compatible with the PHP version.

Integrating it: [`llms.txt`](llms.txt) (one page, copyable) and [`examples/`](examples). What is
stable: [`API.md`](API.md).
Status, plan and every departure from the PHP version: [`docs/port/spec.md`](docs/port/spec.md),
[`docs/port/decisions.md`](docs/port/decisions.md). Working on it: [`AGENT.md`](AGENT.md).
